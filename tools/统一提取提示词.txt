Claude 账号受限观察站：统一离线提取说明与辅助提示词
提示词版本 1.0.0 · 研究协议 1.0.0 · 提取工具 1.0.0 · 结果 schema 1.1

先说明边界
只收集本人核对的脱敏结果，不上传原始聊天、截图、账号、邮箱、IP、精确日期、路径或凭据。不要把原始日志交给 Claude 订阅、其他云模型或网页。统一脚本只在本机统计元数据；不联网、不修改系统、不登录、不规避限制、不判断处罚原因。
正常使用者也欢迎参加，作为同期对照。限制组与恢复组使用第一次受限前的 14 个完整日；正常组使用最近 14 个完整日，期间未受限且有实际使用。脚本按执行机器当前时区统计，不包含锚点当天。若当时移动过时区，请在网页将完整覆盖选为未知或否。

运行方法
1. 从观察站下载 claude-study-extract.py，并保存在本机。需要 Python 3；不需要安装任何 Python 依赖。脚本不会下载软件。
2. 在保存脚本的目录打开终端。首次受限日只填在本机命令里，不会写进结果（只保留月份）。替换下面日期后运行：
   macOS / Linux:
   python3 claude-study-extract.py --anchor 2026-10-01 --output claude-study-result.json --prompt-version 1.0.0
   Windows（若使用 Python Launcher）:
   py -3 claude-study-extract.py --anchor 2026-10-01 --output claude-study-result.json --prompt-version 1.0.0
   正常组省略 --anchor 即默认本机今天。
3. 默认只读 ~/.claude/projects 下的 .jsonl，可包含 subagents。日志在其他目录时加 --root "实际项目日志目录"。不读 settings、.claude.json 或登录凭据；不跟随符号链接。
4. 可选：希望统计 Magpie 的历史路由元数据时，加 --gateway-routing "实际 routing 日志目录"。只读 routing*.jsonl / routing*.jsonl.gz 的 provider 和时间；发现窗口内 provider=claude 才标为 yes。没有日志或没有对应行保持 unknown，不能当作没有中转。普通 VPN/网络代理不等于订阅 OAuth 中转。
5. 用本机文本编辑器打开结果 JSON，确认没有聊天、账号或其他秘密。到观察站导入结果，人工填写能确认的字段；不知道就保留 unknown。核对后再自行勾选汇总授权并提交；脚本不会自动上传。

版本记录与共同改进
结果的 provenance 分别记录研究协议、提示词和提取工具版本。使用本文件原版提示词帮助运行时，请明确传 --prompt-version 1.0.0；直接自行运行、没有使用提示词时可以省略此参数，默认 not_used。不确定是否使用过、使用改写提示词或未注册的 fork 时传 --prompt-version unknown。版本由参与者声明，脚本不验证提示词是否被模型执行，也不保证模型完全遵守。不要把无法确认的版本填成 1.0.0。

欢迎 Fork、PR 和评论。发布过的版本对应固定文本与规则；修改提示词、提取脚本或研究协议之后，不能继续沿用原版本标识，也不能自行声称是本项目官方版本。未注册的改版先标 unknown，经过版本注册与审核后再纳入支持列表；修改脚本的人应同步标记其 extractor_version 为 unknown，待审核注册。网页需要同样保留这个未知状态。
下载目录的 versions.json 记录发布 v1.0.0 与这些版本，并提供脚本和本提示词文件的 SHA256，方便本机核对是否与发布文件一致。文件哈希只证明内容一致，不能证明你执行过文件或单独证明发布方身份。无需提交任何运行记录、原始日志或身份数据。

统计含义与限制
assistant 的正常响应先按 requestId 去重，缺失时按 message.id，再缺失时按 uuid，均没有才按独立记录。流式片段不重复计数；model=<synthetic> 不计作正常响应，API 错误另计。只统计本机留存记录；活跃天数与 00:00–06:00 活跃天数按正常响应时间。版本采用观察窗中最后一个有效 major.minor.patch 版本。数量仅输出区间，不输出精确数值、会话 ID 或日期。
脚本不能知道云端缺失、删除、归档到其他地方的记录，也不能分辨多个账号共用的日志目录。因此 window_complete 默认 unknown，log_coverage 仅表示留存记录；读取异常时为 partial。无可识别时间元数据则 no_logs，所有使用量指标为 unknown，不能把无日志当作零使用量。
同机多个账号混用时，请选择能明确属于这个账号的 --root；无法分离就不要声称指标属于单账号，将完整覆盖填写为否并保持不能确认的指标 unknown。受限后换账号的日志不要加入受限前窗口。一次提交对应一个账号的一个观察窗；不要为补样本重复提交同一个账号。
任何字段都不能推断封禁原因或个人风险评分，不能依据单个分桶判断谁违反政策。研究得到的是观察性关联，公开汇总也不代表所有用户的发生率。

如未安装 Python，可直接在网页手动填写本人确认的结果，不要将原始日志上传给任何服务替代本机提取。
